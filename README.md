# BOOSTE : BOîte à Outils pour Scénariser Ton Enseignement

## Description
The BOOSTE plugin is an online tool for pedagogical scenario design. It comes in the form of an additional plugin in Moodle. It allows for the creation, modification, and sharing of pedagogical scenarios built according to a process of questioning and steps that guide the teacher in defining the learning outcomes targeted by the teaching, the learning activities, and the assessment methods to be put in place.
Learn more about BOOSTE : https://savoir.ensam.eu/moodle/course/view.php?id=10700

## BOOSTE's learning outcomes
• Assist the teacher in designing or improving their teaching autonomously and to avoid starting with a blank page.
<br>• Provide a tool that guides the teacher through all the stages of scenario design up to the deployment of their course in a space on Moodle.
<br>• Create and feed pedagogical activity banks and scenarios.
<br>• Ensure the pedagogical alignment of their teaching.
<br>• Reevaluate their existing courses.

## Installation

Prerequisites :
<br>• Moodle version :	Moodle 5 or later version 
<br>• PHP version: Minimum PHP 8.2.0 for Moodle 5.0/5.1; PHP 8.3.0 minimum for Moodle 5.2/5.3
<br>• MySQL version: Minimum 8.4
<br>• PHP Sodium extension: Required
<br>• PHP max_input_vars parameter: Must be greater than or equal to 5000
<br>• PHP architecture: 64-bit required

<br>Installation :
<br>• To install the BOOSTE plugin, go to the Administration of your Moodle platform. In the Plugins tab, click on Install plugins. 
<br>• Choose to install from a ZIP file; there are two methods to add this file: either by clicking on the Choose a file button, or by dragging the file into the designated drop zone. 
<br>• The installation begins with a series of checks to ensure that all conditions are met to install the plugin. Once validation is complete, click the Continue button to proceed with the installation. 
<br>• The next step is to verify a number of items requested by the server. When the server has all the required items, you can click the Continue button. 
<br>• Click the Update database now button to finalize the installation of the plugin. 
<br>• When the installation is successful, you will receive a success message. Click the Continue button to be redirected to your Moodle platform.
